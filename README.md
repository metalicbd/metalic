# METALIC — Premium Metal Posters Platform (Bangladesh)

> **Metalic** হলো বাংলাদেশের সর্বপ্রথম আধুনিক, মিনিমালিস্ট এবং মোবাইল-ফার্স্ট প্রিমিয়াম মেটাল পোস্টার ই-কমার্স প্ল্যাটফর্ম। এখানে গ্রাহকরা ১ মিমি হাই-ডেনসিটি স্টিল মেটাল পোস্টার ব্রাউজ, সার্চ, কার্ট, এবং ১০০% ক্যাশ অন ডেলিভারিতে অর্ডার করতে পারে। প্রতিটি পোস্টারের সাথে রয়েছে দেয়াল ক্ষতিমুক্ত ৩ পিস হেভি-ডিউটি ন্যানো টেপ মাউন্টিং।

---

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

* **Frontend:** React 18, TypeScript, Vite
* **Styling & UI:** Tailwind CSS (Minimalist Light Theme & Glassy Blue accents)
* **Icons:** Lucide React
* **State Management:** Zustand (Cart & Wishlist with localStorage persistence)
* **Backend & Auth:** Firebase Authentication & Cloud Firestore Database
* **Media Storage:** Cloudinary CDN (সরাসরি ক্লাউড আপলোড ও f_auto, q_auto ইমেজ অপ্টিমাইজেশন)
* **SEO:** React Helmet Async (Dynamic Meta & OpenGraph Tags)
* **Rich Text Editing:** Jodit React Editor (Legal Policies & Compliance Hub)
* **Notifications:** React Hot Toast

## 🇧🇩 বাংলাদেশ মার্কেট স্পেসিফিকেশন

1. **পোস্টার স্পেসিফিকেশন:**
   * **ম্যাটেরিয়াল:** ১ মিমি হাই-ডেনসিটি হেভি-গেজ স্টিল (মরিচারোধী)।
   * **ডাইমেনশন:** `20 × 30 cm` (পোর্ট্রেট) অথবা `30 × 20 cm` (ল্যান্ডস্কেপ)।
   * **মাউন্টিং:** প্রতিটি অর্ডারের সাথে **৩ পিস হেভি-ডিউটি ন্যানো টেপ অন্তর্ভুক্ত** (দেয়ালে কোনো ছিদ্র করার প্রয়োজন নেই)।
2. **ডেলিভারি চার্জ সিস্টেম:**
   * **ঢাকার ভেতরে (Inside Dhaka):** ৳৮০
   * **ঢাকার বাইরে (Outside Dhaka):** ৳১৩০
3. **পেমেন্ট সিস্টেম:** ১০০% ক্যাশ অন ডেলিভারি (Cash on Delivery)।
4. **ইউনিক ট্র্যাকিং:** প্রতিটি অর্ডারে `MET-XXXXX` ফরম্যাটে ইউনিক ট্র্যাকিং আইডি জেনারেট হয়।
